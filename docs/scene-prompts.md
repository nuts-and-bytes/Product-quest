# 章节与夜市的单一交互提示 · v3.10.2

八个岛上章节的人物与证据、第一章的五张实体方案卡，以及夜市人物、摆台和排队顾客，共用 `PQScenePrompts`。场景内只保留小圆点；一个独立操作条显示当前目标。Q /「切换」只改变焦点，E / 点击操作条调用原来的交互。直接点人物、实物和原有任务面板仍然可用。

提示位置避开主角全身、其他人物上半身、可交互实物、任务面板与手机安全区域。无法贴近实物放置的小圆点隐藏，目标仍可从操作条切换到。操作条优先保留当前安全位置；最窄横屏可以上下排列两个按钮，触控区域至少 44px。交谈、镜头转场、生活演出和全屏检视期间不响应背景快捷键。检视返回后保持目标；夜市新客到来不抢走焦点，离开的客人不能通过旧提示继续操作。

渲染沿用现有场景循环，人物、光照、粒子、几何与纹理不变。实物包围盒在初次使用时缓存，界面遮挡区域按需测量；没有额外 RAF、材质或渲染器。
