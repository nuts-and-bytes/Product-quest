# 户外镜头与可见性 · 3.8.2

岛上漫步默认保持半径 54、极角 0.8 的高视角。开始任务导航、定位自己、进出办公室或章节时保留玩家选择的距离与方位；漫步缩放限制为 30–96，极角限制为 0.55–0.9。第一人称仍为独立选项。

## 遮挡处理

`assets/world-visibility.js` 保护主角和附近的当前目标人物。总部引导期间也保护同行的夏青。对镇上建筑、树木和气球每 80 ms 做一次包围盒筛选及头、胸、脚三条视线检测。连续遮挡 120 ms 后让开，连续恢复 220 ms 后收回，避免树边与建筑边缘闪烁。

只裁掉遮挡物在人物周围、位于人物前方的一小块屏幕区域。对象各自拥有材质和裁切权重，继续使用不透明深度测试、原有阴影及既有后期处理；不整栋透明、不增加全屏渲染通道。过渡期间用一份合并的人物几何提供金色轮廓提示，视线清晰后恢复角色原材质。昼夜发光强度继续与原材质同步。室内、生活演出、群岛全览及第一人称停止裁切。换装时释放旧提示几何与材质。

让开部分的建筑点击代理同步忽略，玩家可以点击露出的地面走路；建筑入口仍通过任务按钮或附近交互进入。气球航线外移、抬高，减少横穿岛心的巨大前景。

## 界面和构图

- 任务卡默认只显示当前任务、进度、一个行动按钮；详情与章节地图按需展开。
- 视角工具、探索手记、画质和原有存档菜单收进「视角」「更多」。保留原按钮及事件，打开时停止自动行走，Escape 关闭并返回按钮焦点。进入章节或重放新手引导时收起菜单。
- 主角、同行人物、当前目标优先排布，避开任务卡、操作区、人物身体和其他标签。先寻找人物附近的空位，再停靠屏幕边缘；目标离屏时显示方向提示。附近建筑标签最多显示两个。
- 漫步镜头有小范围跟随死区；面板占据画面中央时平移构图，让主角保持在可见区域，不靠突然拉近镜头解决问题。
- `assets/world-framing.js` 包含独立可测的镜头约束、标签排布、安全区域与遮挡迟滞规则。

## 验证

2026-11-18：81 项 Node 测试通过。浏览器检查使用独立 `?player=visibility-*` 存档，部分场景使用位置与章节状态夹具，不修改真实玩家存档。

检查了首次创建角色、与夏青交谈、走到总部、进入/退出办公室、章节入场生活演出、章节往返、八个环绕方向、遮挡区地面点击、任务详情、菜单、取景与 Escape。1440×1000、390×844、320×740、844×390 下，任务卡展开/收起时没有检测到主角/目标标签覆盖界面障碍物、越界或横向页面溢出。

同一浏览器单标签页，1200×794、电影画质第 2 档、相同角色位置与镜头，分别采样约 8 秒：

| 指标 | 3.8.1 | 3.8.2 |
| --- | ---: | ---: |
| 平均 FPS | 29.59 | 29.67 |
| P95 帧耗时 | 41.7 ms | 41.7 ms |
| 记录到的 render calls | 414 | 415 |

这是本机短时对比，不代表所有设备的帧率。三次章节往返后资源数量稳定在 310 份几何、19 份纹理、24 个着色器程序；连续三次重建角色后几何与纹理数量也保持稳定。保留自动画质和减少动态偏好。

单文件 HTML 约 1.71 MiB，在 `file://` 下启动并进入遮挡场景，记录到的外部资源请求为零、着色器编译失败为零。另一次约 8 秒的遮挡场景采样为 29.69 FPS、P95 41.7 ms（1200×794、第 2 档）；该采样只验证此场景运行，不作为与不同场景的速度对比。
