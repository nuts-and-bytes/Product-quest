# 蓝山的日常与全屏物件检视 · 3.9

## 可玩的变化

普通咖啡馆补上了独立的场景点击入口。点人物模型和对应按钮走同一条交互路径；点窗户进入观景，柜台明信片、窗边便笺和杯子可以拿起来。原因是旧的岛上点击在室内主动返回，咖啡馆调查另有自己的拾取器，而普通生活模式只有菜单按钮。修复没有改变岛上跑图的高视角。

柜台、窗边和海风露台各有当前场景。常驻操作只保留本处两三个选项，调查、夜市和离开收在「还有别的约定」里。露台展示正在渲染的真实岛屿，可看星火海湾、花信步道和蓝山屋檐；沿用水面、灯光、粒子、岛民和交通，不加载视频或第二个持续渲染器。

两条可完整完成的隐藏故事：

- **把海风寄给你**：拿起未寄出的明信片 → 翻背面发现小美的留言 → 到露台选择一处真实风景 → 回到卡片，选择贴在店里或和小美的信一起寄给妈妈。风景会改变卡面的插画；选择会留下墙上的卡片或待寄信封，并改变小美后续对白。
- **给一个人留座**：翻杯碟下的便笺 → 问李姐门外犹豫的人 → 拿杯子选择安静的窗边或可以聊天的拼桌。阿凯推门走来，坐到对应位置；拼桌会新增桌凳，之后可直接点阿凯聊天。动画可跳过，减少动态效果时直接就位。中途离开仍保留已经做出的选择。

故事保存在 `G.cafeLife`，使用白名单和前置条件恢复。重复查看不会重复推进或改写结局；不扣咖啡馆调查行动、不改章节完成记录和夜市账本。已有存档无需重开。

## 物件在眼前

统一检视器覆盖咖啡馆物件和调查证据、八章已有的证据道具、第一章实体方案卡、夜市信封与经营记录。便笺、信封、收据、台历、屏幕、硬币和杯子按物件形态显示。装饰植物、固定家具等背景布景不在本轮检视范围内。

检视占满游戏视口：拖动旋转，双指或滚轮缩放，按钮翻面、摆正；阅读按钮提供清晰、可滚动的原始记录。键盘方向键、F、加减号、Tab 和 Escape 可完成相同操作。小屏按顶部标题与底部操作的实际尺寸留出物件空间。横竖切换保留当前物件、朝向和阅读状态，放回时适配当前视口并恢复原场景。

证据仍来自原有模型：首次调查仍按原规则扣行动，重复查看免费；放回订单可继续刚才的对话，也能圈证据或拿订单问阿晨。第一章卡片先检视，再选择放入或撤回，原有卡片列表仍可快速操作。夜市检视期间暂停场景计时，放回继续原摊位状态。

## 生命周期与性能

`prop-inspector.js` 临时借用现有 Three 渲染器及唯一帧循环，使用独立的小场景呈现物件，暂停背后活动。关闭时恢复场景、相机、界面可操作状态和焦点，释放本次创建的几何、材质和纹理。不使用第二个 WebGL context、持续截图或新后期通道。

`cafe-life.js` 只给当前咖啡馆挂一次拾取事件。进入调查或离开时解绑；同一个房间复用道具，房间销毁时统一释放。露台先设置当帧相机，再更新天空、光照与模型细节级别，避免拿室内近景镜头为户外模型选细节。

## 验证记录

2026-11-18：91 项 Node 测试通过。新增状态测试覆盖旧存档、未知输入、翻面发现、完整前置条件、重复操作和结局保护。

`scripts/qa-cafe-interaction.mjs` 在真实浏览器以原生鼠标点击人物模型：修复前断言失败，修复后通过。`scripts/qa-cafe-immersion.mjs` 覆盖两条故事完整流程、刷新恢复、主存档隔离、横竖屏旋转、568×320 的可见按钮边界及最小 44×44 触点、Escape 关闭、章节证据返回原对话、卡片选择撤回、订单不重复扣行动和夜市状态恢复。`scripts/qa-props.mjs` 逐一核对九种章节物件、原始记录、拖动、双指缩放及旋转后的镜头恢复。测试使用独立 `?player=cafe-39-*` 存档；部分已解锁章节采用测试夹具进入。

`scripts/qa-cafe-performance.mjs` 在同一浏览器、1200×794、晴昼、电影画质第 2 档、同一高视角各采样 160 帧：3.8.3 为 27.66 FPS / P95 41.9 ms；本版为 27.63 FPS / P95 41.7 ms。咖啡馆为 29.22 FPS，检视为 29.13 FPS。四轮道具检视与露台往返后资源均为 507 份几何、27 份纹理、31 个程序；计数与所访问的场景和人物有关。短时桌面对照未观察到明显退化，不能据此宣称所有手机达到相同帧率。

单文件构建仍由 `scripts/build-single-html.mjs` 完成，约 1.79 MiB，无外部运行依赖。手机检查采用 Chromium 尺寸与触控模拟，真实 iPhone / Android 的浏览器全屏和方向锁定仍需设备验收。
