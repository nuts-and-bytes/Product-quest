# 阿晨的 3D 对话 · 3.5

蓝山调查的第一段人物交谈现在发生在同一个 3D 房间里。探索时点击阿晨或头顶标识，镜头靠近双方；请他指出等候位置时，两人走到柜台前。订单是柜台上的实体物件，也有触屏和键盘可用的文字入口。

## 交互

- 探索：突出阿晨，保留柜台订单、店员与观察现场入口。首次取得材料会标明行动消耗。
- 交谈：上下文回应、人物转向与轻微动作、手动推进、18/22 px 台词、最近 24 次回应的历史。走到柜台后继续追问和看证据会保持站位，结束交谈才回到探索。没有倒计时或自动跳字。
- 证据：单独阅读订单或讲述，固定的返回按钮恢复原话题。带订单追问会触发对应情境的回应。阅读已取得的资料不重复扣行动。
- 观察：主动进入早高峰重放，可暂停、重看、返回店里。交谈与读资料不会继续播放顾客离开的时间线。
- 方案与后果：沿用 3.3 的预算、模拟、复盘及长期物件。没有批量改写其他章节。

`Escape` 依次关闭资料/帮助、谈话历史或交谈。所有主要入口都有原生按钮与键盘焦点；选完回应后焦点回到新台词。手机保留人物画面，证据使用独立资料页，次要地点入口避免堆在人物头顶。

## 状态与资源

`cafe-dialogue.js` 是独立可测试的作者编写对话图。`cafeCase.dialogue` 仅保存经过校验的节点和回应 ID；旧存档补充初始节点，既有调查、主线及信任度保持原值。首次询问沿用原模型的证据消耗，始终保留一次试验机会。下一个情境重置对话，旧情境物件仍保留。

使用现有 `PQStory3D` 相机、`PQIsland` 角色与自适应渲染。没有增加 WebGL 上下文、常驻动画循环或联网对话服务。少量订单物件复用房间几何体与材质；临时角色和点击监听随调查关闭回收。减少动态效果偏好下，走位/镜头直接就位、人物小动作停止、重放默认暂停。

## 3.5 · 动作与交互衔接（2026-11-17）

- 点击阿晨后先转向、靠近，再进入双人构图。台词与回应按顺序出现；重复进入会缩短等待。
- 请阿晨带路时先示意，阿晨先走、主角随后跟上。镜头持续跟随，双方抵达柜台后展开台词。
- 每次回应只播放一次简短的点头、回忆或指向动作，随后回到自然站姿。读订单期间保持原站位，停止交谈动作；关闭资料回到原话题。
- 结束交谈先点头告别，再拉开镜头、恢复探索提示。侧边顾客随构图切换显示，避免在镜头靠近的第一帧消失。
- 镜头位置、视线、屏幕构图偏移和面板入场使用同一条短时间线。没有独立计时器、播放队列或新渲染循环；选择立即保存，动画不负责提交剧情或扣除行动。
- 动作开始时提供「跳过动作」，键盘焦点进入该按钮，Enter 可立即完成；Escape 可以中断并返回。其他工具操作也会先完成当前过渡，避免旧动作稍后覆盖新界面。
- 脚步与翻纸音使用已有音频上下文并遵守全局静音设置。「帮助」内可开关音效和减少动态效果；系统的减少动态偏好优先。关闭调查会回收角色、监听与临时时间线。

验证：39 项 Node 测试通过；桌面 1440×900、手机视口 390×844、320×740（22 px 台词）检查，页面无横向溢出。实际浏览器走通带路、订单阅读、返回原话题、核对订单、告别和再次进入；Enter 跳过、Escape 中断、应用内减少动态和静音开关通过。主线进度与信任度保持 QA 初始值（0 / 100），同一证据没有重复扣行动。

同机同档位（电影档 tier 2）稳定交谈各采样 5 秒：改动前后帧间隔中位数均约 8.4 ms，P95 约 16.7 / 16.8 ms；绘制次数均为 410，几何体均为 585。此记录为当前桌面浏览器，不代表真实低端手机。连续三次关闭调查后几何体回到 460、纹理保持 25，临时顾客为 0，点击监听与动作时间线均释放。

补充检查：系统减少动态偏好下动作与镜头直接就位、重放默认暂停；单文件 HTML 从本地文件打开后进入交谈，运行时资源请求为 0。
