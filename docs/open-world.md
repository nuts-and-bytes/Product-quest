# 开放群岛与电影画质

基于主分支 `0c69d3996d447a1f637c80dc5c665d2054427b36` 开发，保留原有 37 关、71 个术语、角色编辑、方法卡、档案馆、作品集与导入导出存档。

## 可玩的内容

- 首页直接展示实时 3D 世界，拖拽环视、切换昼夜。新玩家进入角色创建；已有进度的玩家直接继续冒险。
- 三条可行走栈桥连接星火岛、琥珀林地、星潮观测站和珊瑚花园。每个外围区域有地标、可保存的探索手记和原主线关联。
- 点击地面通过 A* 绕开建筑、水域和信标底座；WASD、方向键、手机摇杆自由行走，Shift 奔跑。
- 完成序章或章节最终关卡，对应建筑出现永久金色标记；点击建筑可回顾该章成果、查看关卡评级、重玩、触发粒子庆典。奖励直接从旧存档的 progress 推导。
- H 取景、J 手记、E 互动；支持昼、昏、夜、实时钟与自动昼夜。

这是四岛连续开放区域，尚未实现无限程序生成、区块流式加载、联网多人或新增完整大陆课程。

## 光影与性能预算

- 统一体素颜色的 sRGB → linear 转换，降低角色过强的自发光，使用 ACES 色调映射。
- 程序化天空、星空带、菲涅尔水面近似反射、波纹、日光高光与沿岸泡沫。没有真实平面反射、实时光追或全局光照。
- 电影档：半浮点 HDR、四分之一分辨率辉光、深度遮挡光束、轻量屏幕空间环境遮蔽、轻微远景柔化、色彩分级与暗角。普通 HDR 渲染 5 次场景/屏幕绘制，电影档增加 1 次低分辨率光束绘制。
- 花瓣、流萤、水雾、喷泉、空气微尘和庆典在 GPU 上更新；草叶使用实例化与风动。
- 环路与支路的 374 个静态对象合批；远景角色使用低分段球体/胶囊体，并合并网格，靠近后恢复原模型与动作。
- 阴影范围随角色移动，1024/2048 阴影分档；像素比上限分别为 0.85 / 1.15 / 1.6，避免 Retina 无上限放大。
- 自动模式默认启用：每 3 秒评估实际帧耗时。持续低于约 48 FPS 或较多长帧时降档；有充足余量持续 18 秒且降档冷却已过 30 秒后才尝试升档。严重连续卡帧也会降档。忽略后台与孤立加载停顿，切到后台时暂停 3D 循环。
- 允许手动电影 / 均衡 / 流畅。手动电影档保留最高效果，设备掉帧时应切回自动。缺少浮点渲染支持时直接渲染基础场景。

帧率取决于设备、窗口大小、浏览器与同时运行的其他页面。当前机器的短时检查观察到自动模式可保持电影档；这不是跨设备 60 FPS 保证。

## 文件边界

- `assets/world-map.js`：区域坐标、栈道、碰撞与寻路。
- `assets/world-quality.js`：有滞后的自动画质调节器。
- `assets/chapter-progress.js`：从旧存档推导九章建筑奖励。
- `assets/world-environment.js`：天空、水、后处理、实例化植被、粒子、远景角色、探索与建筑视觉。
- `assets/world-ui.css`：实时 3D 首页、地图 HUD、建筑成果面板与手机适配。
- `assets/island3d.js`：保留原模型、相机与角色，接入新渲染与导航。
- `engine.js`：保留原剧情流程，存档新增 exploration；接入章节成果与庆典。
- `scripts/build-single-html.mjs`：内联本地脚本与样式，移除远程统计，构建独立 HTML。

## 扩展方式

下一片区域需要同时扩充空间规则、场景与可玩的内容。数十个区域以上应先加入区块装卸与资产生命周期管理。单文件 HTML 是当前交付形式；更大世界可保持浏览器运行，改用按需加载资源。
