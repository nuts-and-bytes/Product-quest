# 咖啡馆室内行走 · v3.10

普通蓝山咖啡馆（`?experience=cafe-life`）从静态观察改为角色行走。室外继续使用已有的高视角；调查、章节、夜市继续使用其任务模式。

- 点地面行走；WASD / 方向键或手机摇杆直接移动，自动路线随即取消。
- 点人物或物件先走到交互位置。靠近后可按 E 或点提示按钮；可达位置按桌椅、吧台、植物、NPC 和新增拼桌共同计算。
- 默认跟随角色，拖动画面左右环顾；「查看全景」保留找位置的能力。顶面和前景墙、门框随镜头所在位置显隐，避免阻挡镜头。
- 「柜台」「窗边」「海风露台」会让角色实际走向对应位置。露台仍使用原有岛屿观景模式，并不是室外自由步行场景。
- 大面板收进「馆内手记」。人物对白、检视、来客演出、失焦和旋转会清除移动输入；关闭检视后不会继续旧路线。
- 移动只使用当前房间、现有角色和渲染循环。脚步声复用既有音频与静音开关。不修改主线进度或存档结构。

## 验证

`node --test tests/*.test.cjs`：95 项通过。导航测试覆盖所有互动目标、拼桌后的通路、障碍物绕行、斜向速度、长帧碰撞和不可达目标。

浏览器脚本通过 ego-browser 的 Node 环境导入后调用 `run(page)`：

- `scripts/qa-cafe-walking.mjs`：实际画布点选 NPC 与地面、先走近再交谈、键盘接管、E 互动、碰撞路线、检视暂停、真实触摸摇杆、横竖屏切换、观景往返、调查模式隔离和重新进入。
- `scripts/qa-cafe-immersion.mjs`：明信片与留座完整支线、刷新保留、主线数据不变、道具全屏与手机控件边界、章节卡片、调查行动以及夜市状态。
- `scripts/qa-cafe-walk-performance.mjs`：与提交 `3edb462` 对比，1200 × 794、cinema 档，预热 35 帧后各采样 150 帧。旧版、当前站立、当前行走均约 29.2 FPS，P95 41.7 ms。反复进入调查、道具和观景 4 次后资源稳定为 507 geometries / 27 textures / 31 programs。测量是此浏览器环境的相对比较，不代表真机手机帧率。

单文件 HTML 通过 `scripts/build-single-html.mjs` 构建，约 1.81 MiB；仅打包当前资源，不依赖额外模型服务。
