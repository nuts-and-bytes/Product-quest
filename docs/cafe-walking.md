# 咖啡馆室内行走 · v3.10

普通蓝山咖啡馆（`?experience=cafe-life`）从静态观察改为角色行走。室外继续使用已有的高视角；调查、章节、夜市继续使用其任务模式。

- 点地面行走；WASD / 方向键或手机摇杆直接移动，自动路线随即取消。
- 点人物或物件先走到交互位置。靠近后可按 E 或点提示按钮；可达位置按桌椅、吧台、植物、NPC 和新增拼桌共同计算。
- 默认跟随角色，拖动画面左右环顾；「查看全景」保留找位置的能力。顶面和前景墙、门框随镜头所在位置显隐，避免阻挡镜头。
- 「柜台」「窗边」「海风露台」会让角色实际走向对应位置。露台仍使用原有岛屿观景模式，并不是室外自由步行场景。
- 大面板收进「馆内手记」。人物对白、检视、来客演出、失焦和旋转会清除移动输入；关闭检视后不会继续旧路线。
- 移动只使用当前房间、现有角色和渲染循环。脚步声复用既有音频与静音开关。不修改主线进度或存档结构。

## 桌边提示 · v3.10.1

同一时刻只展开当前目标的操作。物件和人物使用小标记，Q 或「切换」轮流选择附近的目标；当前选择会保持到离开交互范围。拥挤时标记可以隐藏，物件仍能从统一提示中选择。主角的屏幕投影、NPC 上半身与操作控件共同参与避让，移动或交谈时暂时收起提示。

`scripts/qa-cafe-prompts.mjs` 验证单一操作提示、目标选择稳定、便笺与杯子均可检视、触摸切换、44px 点击范围、无相互遮挡、844 × 390 / 568 × 320 / 390 × 844 排布、全景往返和存档不变。原有 `qa-cafe-walking.mjs` 行走回归也通过。不增加 3D 对象或渲染循环。与当前主分支同步后，98 项自动测试通过，离线 HTML 约 1.86 MiB。
