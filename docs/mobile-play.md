# 横屏、人物侧边对话与桌面卡片 · 3.8.3

## 玩家体验

手机旋转后，场景继续运行，当前对话、方案和经营进度保持。横屏把交谈和阅读放在人物侧边；短屏幕上的面板内部滚动，继续交谈、开始试用与营业操作保持可达。桌面宽屏的对话按内容高度显示在人物旁，竖屏继续保留上下布局。

顶部提供触屏全屏入口。支持时先进入全屏，再请求横屏锁定；不支持或拒绝时仍能手动横过手机游玩。退出全屏只释放本次取得的方向锁定。不会用 CSS 旋转页面，不以接口存在或请求完成推断已经锁定。

首页、创建角色、工牌、岛上引导、章节、咖啡馆、夜市与生活演出适配短横屏。界面避开四边安全区；移动摇杆与视角工具分居两侧。旋转时清理未结束的方向键、触点和摇杆状态，不重新初始化游戏或清空自动导航、剧情与存档。

## 把动作放回场景

- 八章里的证据物件：选中后镜头对准实物，物件抬起、放大和倾斜；退出查看时归位。详细内容仍在可滚动的阅读面板中。
- 第一章工作台：五张工具与开始方式卡摆在实体桌面上。可以直接点击卡片或标签，放入两个试用位置；同类替换、再次点击撤回，试用沿用原有模拟结果。
- 触控标签在卡片移动时保持落点稳定，避免连续点选时按钮跟着动画跑。保留完整的「卡片列表与说明」、键盘按钮和选择状态。
- 卡片仅编辑原有草稿方案，撤回不会删除试验历史或首次完成记录。减少动态效果时立即就位。

这一轮的实体卡片样板只覆盖第一章；其他章节继续使用各自的流程、原型、数据和报价玩法。后续适配应逐章设计对应动作，而非将所有文字面板贴成 3D 纹理。

## 实现约束

`mobile-play.js` 管理全屏、方向切换、安全区和场景标签避让。只在尺寸、方向和屏幕切换事件中合并同步工作；标签布局复用现有 `world-framing.js`，障碍物测量间隔 160 ms，缓存标签尺寸。

`chapter-table.js` 使用当前房间与同一渲染器，只创建当前章节的五张卡。动画在现有帧循环里更新，离开释放几何、材质、文字纹理和 DOM。没有新加持续渲染循环、后期通道或网络模型资源，原有光照、粒子、画质分档与高视角跑图保留。

## 验证范围

2026-11-18：87 项 Node 测试通过，包含全屏缺失、拒绝、锁定失败、实际全屏状态与调用顺序，以及撤回方案后的存档与历史保护。修改的 JavaScript 完成语法检查。

浏览器在独立 `?player=landscape-*` 与离线测试存档中验证；部分已解锁场景通过测试夹具进入。检查了 844×390、667×375、568×320、390×844、1440×1000 布局，以及模拟刘海安全区。包括首次创建角色和工牌、与小美交谈、阿晨交谈和订单证据、3D 卡片点击与撤回、试验演出、夜市接单制作交付、全屏进入退出、横竖屏切换。

三次章节往返后资源计数保持 861 份几何、19 份纹理、24 个着色器程序，未随往返增加。该计数包含本次首次入职与换装流程创建的世界对象，不与其他位置或存档下的资源总量直接比较。

同一浏览器、1200×794、同一岛上位置与高视角、晴昼、电影画质第 2 档，各取 200 帧：3.8.2 与本次版本平均均为 29.60 FPS，P95 帧耗时均为 41.7 ms。本次短时对比未观察到退化，不代表所有手机的实际帧率。

浏览器尺寸和触控模拟不能代替真实 iPhone / Android 验收；尤其 iPhone 的浏览器全屏与方向锁定仍依赖系统和浏览器能力。单文件 HTML 约 1.74 MiB，`file://` 下验证运行与卡片交互，没有外部资源请求或着色器编译失败。

## 浏览器依据

- [Fullscreen 标准](https://fullscreen.spec.whatwg.org/#dom-element-requestfullscreen)：用户操作中的全屏请求与失败处理。
- [Screen Orientation 标准](https://www.w3.org/TR/screen-orientation/#interaction-with-fullscreen-api)：方向锁定与全屏条件。
- [WebKit 安全区说明](https://webkit.org/blog/7929/designing-websites-for-iphone-x/)：`viewport-fit=cover` 与四边安全区。
- [Chrome 视口与软键盘行为](https://developer.chrome.com/blog/viewport-resize-behavior)：布局视口和视觉视口存在差异。
- [WCAG 方向要求](https://www.w3.org/WAI/WCAG22/Understanding/orientation.html)：保留可用的竖屏访问，不强制阻断。
